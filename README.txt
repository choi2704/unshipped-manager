KD 미출고·반송 관리 v3

1. ZIP 압축을 풀고 index.html 파일을 열거나 GitHub 저장소에 업로드하세요.
2. GitHub Pages를 켜면 기존 주소(예: https://choi2704.github.io/kd-sales/)에서 사용할 수 있습니다.
3. 사방넷 > 주문서확인처리에서 물류메세지 '송신완료후미출고' 검색 후 '전체 데이터' 엑셀 다운로드.
4. 웹 화면에서 엑셀 선택 > 엑셀 등록. 물류메세지에 '송신완료', '미출고' 모두 들어 있는 행만 등록됩니다.
5. 중복 주문은 건너뛰고, 기존 주문의 처리 상태와 관리 메모는 그대로 유지됩니다.
6. + 수기 등록으로 주문을 직접 입력할 수 있습니다.
7. 주문 수정/상태변경에서 반송예정을 선택하면 맨 앞 대시보드 '반송예정' 숫자에 반영됩니다.
8. 상단 '백업 JSON'을 주기적으로 클릭해 데이터 백업을 보관하세요.

주의사항:
- 이 프로그램은 브라우저의 로컬 저장소에 데이터가 저장되므로 브라우저/기기 간 자동 동기화가 되지 않습니다.
- 브라우저 데이터를 삭제하면 저장된 주문도 사라질 수 있습니다. 백업을 반드시 보관하세요.
- 사방넷 주문의 개인정보가 포함되므로 백업 파일과 사용 기기의 접근 권한을 관리하세요.
- 엑셀 파서는 SheetJS CDN을 사용하므로 최초 엑셀 업로드 시 인터넷 연결이 필요합니다.
- 기존 GitHub Pages가 index.html 기반이라면 index.html을 교체하는 방식으로 설치할 수 있습니다. 단, 기존 앱의 데이터 키/스키마가 다른 경우 자동 이관되지 않습니다. 기존 사이트 데이터를 별도 백업해 두세요.
